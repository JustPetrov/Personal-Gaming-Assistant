# Personal Gaming Assistant

Self-hosted gaming assistant for a VPS.

## Schedule
- 08:00 — normal full update
- 12:00 — normal full update
- 20:00 — normal full update
- 22:00 — normal update + Late Night Round Up

## Core modules
- GamesCom (yearly), event-day filtering and entry alerts
- Hotel Watcher / Ticket Watcher
- Steam and PS5 Game Price Watcher
- SteamDB primary Steam pricing with EUR + UAH
- UAH Deals comparison
- Discord Price Watcher
- Wishlist Price Watcher
- RAM/Rammegadon Watcher
- GPU/GPU Doomsday Watcher
- Current price, stock, direct link and source
- Local and Netherlands time/date display

Secrets are supplied through environment variables and never committed.
