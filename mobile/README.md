# Personal Gaming Assistant Mobile App

The mobile client is designed as a companion to the VPS dashboard.

## Planned/runtime capabilities

- Dashboard overview
- Latest 6 updates
- Live prices
- Wishlist: Game / Hardware / Gear
- Steam profile
- GamesCom status + countdown
- Manual update
- Push-notification registration
- Alert feed

The mobile client talks to the VPS API; secrets and watcher credentials stay on the VPS.

Recommended implementation target: Expo React Native so one codebase can build Android and iOS.
